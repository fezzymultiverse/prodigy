# Prodigy Syncing V90
S.O.I. × Bojack Security · 999

A music, video, gallery and AI app for Android, built as one HTML file (`www/index.html`) wrapped by Capacitor, with a native Java layer for background playback, downloads, sharing and the in-app browser. The same file also runs as an installable web app (PWA).

## Features
- **Music**: import from the phone (Add whole library adds every song on the phone in one go), folders, playlists, favourites, most played, recently played, notes per song, queue, shuffle / repeat, sleep timer, playback speed, A-B loop, equaliser, background playback with notification and lock-screen controls (APK).
- **Lyrics**: LRCLIB, then Genius (APK), then lyrics.ovh; synced lines highlight in cyan; edit, search and clear.
- **Lyric image**: 1080x1350 card with the song artwork. Styles Blur / Full art / Dark, choose lines or type your own. Share to WhatsApp, Facebook, Email, any app, or save to Pictures/Prodigy.
- **Metadata and artwork**: iTunes, Deezer and Genius lookup fills empty tags; a generated black/cyan cover is used when nothing is found. Artist and song info from Wikipedia plus an AI synopsis.
- **YouTube (V53)**: the red YouTube button (top right) opens the real YouTube inside the in-app browser, with Google sign-in that stays signed in. On any video or playlist page a ⬇ button appears in the bottom bar: Audio (added to the library) or Video (saved to Downloads/Prodigy). Paste Link is still in the YouTube search panel.
- **YouTube**: popup player, download to Download/Prodigy as audio or video, many links or a playlist (max 100). APK only.
- **Videos and Gallery**: persistent libraries stored in the app database.
- **Browser and Facebook**: Chrome-style in-app browser sheet: address bar, real tabs (each tab is its own page with its own back history, kept for next time), bookmarks, history, three-dot menu, bordered Chrome-style Settings (search engine, desktop site, JavaScript, cookies, clear browsing data), downloads, file upload. Open it from the Browser button, first in the top bar. **Facebook** opens inside it (m.facebook.com).
- **Popups**: YouTube, Videos, Spotify, the in-app Browser and Facebook all open from the bottom, half screen. ▾ minimises to a small bar so you can change songs, ⤢ maximises, ▴ restores.
- **Export & Import**: left panel → Console → Export & Import. Saves a JSON backup to Download/Prodigy (or shares it) and merges one back in. The APK also auto-backs up once a week (switch in the same panel); a pill on the dashboard shows when the last backup is older than 7 days.
- **Diagnostics**: left panel → Console → Diagnostics. Version, build, library counts, storage, last backup, failed modules and the error log (this session and the last one), with a Copy report button. Keys and tokens are masked in the log.
- **Spotify**: embed player for track, album, playlist and episode links.
- **AI**: Gemini, Groq and OpenRouter with your own keys, chat, memory and preferences, API Vault (encrypted on the device, auto-locks after 10 minutes).
- **Visualiser**: live waveform, bars or mirror on Now Playing (tap the mode button in the header; Off hides it). To turn every visualiser off at once and save battery, use ⋮ → Visualisers (the header button then reads 🔋 Off). A slim live waveform also runs in the bottom player bar while a song from the phone plays (tap it to change style).
- **Karaoke**: full-screen synced lyrics with a line that fills as it is sung, big text, seek bar and the visualiser behind it. Open from Now Playing or the Lyrics tab.
- **Recorder**: Clean vocals chain (OS noise suppression and echo cancel, high-pass, de-mud, presence, adaptive noise gate, compressor), live mic waveform, Raw mic option.
- **Privacy**: left panel Console, Privacy. What stays on the device, what leaves it and when, switches for online lookups, delete AI chats, S.O.I. disclaimer.
- **Share song**: three dots (bottom player or full-screen Now Playing) → Share song card: artwork, song and artist on a 1080x1350 card, Blur / Full art / Dark, to WhatsApp, Facebook, Email, any app or Pictures/Prodigy.
- **Tools**: torch (phone flash, SOS, strobe, screen light), calculator, calendar, timer, converter, password generator, hash and Base64, random, quick capture, snippet vault.
- **Termux Handbook**: the Termux button next to YouTube (top right) opens a searchable list of 237 Termux tools in 19 groups (bootstrap, system, files, network, OSINT, media, dev, editors, utilities, Termux:API, distros, plus eight one-liner groups: IP, DNS and Ping, Aircraft (Sky Watch), Vehicle Lookup, GitHub Recon, Device Info, Web and Domain Recon, Open Data and Misc, Exposure Checks). Tap a command to copy it, Copy all per group, or tick tools and Copy script for one merged install script (interactive items copy one at a time). Falls back to a select-and-copy box if the phone blocks clipboard access.
- **Auto-minimise player**: the bottom Now Playing bar shrinks to its mini form while you scroll down the song list and expands when you scroll up or reach the top. Your own minimise button (▾) always wins. Switch in Settings → Display and performance.
- **Look**: Fezzy Dark (cyan / black / white) by default, more themes in the palette menu.

## Two builds from one repo
| Build | Workflow | Result |
|---|---|---|
| Pages | `.github/workflows/pages.yml` | Serves `www/` over HTTPS. Install from Chrome. No native features. |
| APK | `.github/workflows/build-apk.yml` | Capacitor + native layer. Artifacts → `prodigy-debug-apk`. |

## Build and deploy
1. Repo Settings → Pages → Source: **GitHub Actions** (once).
2. Push to `main`. Both workflows run.
3. APK: Actions → latest run → Artifacts → `prodigy-debug-apk` → install `app-debug.apk`.
4. The APK build runs `npx cap add android`, then `scripts/patch-android.sh` (copies `native/*.java`, patches the manifest, adds NewPipe and androidx.webkit to Gradle via `scripts/gradle_newpipe.py`), then `cap sync` and `gradlew assembleDebug`.
5. Updating: replace files, push. Bump `APPV` in `www/index.html`, the version text on the boot phone, the cache name in `www/sw.js`, `package.json` and the README title so the PWA refreshes. `scripts/lint.py` runs first in both workflows and fails the build if any of those disagree, if a script has a syntax error, or if the JS wires an element id that does not exist.

## Push and update from Termux (V77)
```
bash scripts/setup-signing.sh      # once: makes the permanent signing key, stores it as GitHub secrets
bash scripts/bump.sh 78 "short note"  # raises the version in every file and runs the lint
bash scripts/push.sh               # lint, commit, push to main; Actions builds the signed APK + Release
```
Install the Release APK over the old app: same key and a higher versionCode means it updates in place and keeps your data. Export a backup first anyway (Console, Export & Import). The first build with a NEW key cannot install over an APK signed with a different key: export, uninstall once, install, import.

## Native bridge (`ProdigyBridge`, APK only)
`update`, `stop` (playback service) · `requestPerms`, `micState`, `requestMic`, `openAppSettings`, `batterySettings`, `torch`, `torchInfo` · `openApp` · `listAudio`, `readChunk` (phone music) · `ytDownload`, `ytCan`, `ytVideo`, `ytPlaylist`, `ytSearch` (NewPipe) · `browse` (in-app bottom-sheet browser: half / minimised / full) · `saveFile` (Export, Android 10+) · `shareImage` (Android 10+, saves to Pictures/Prodigy, targets WhatsApp / WhatsApp Business / Facebook / Email or the system chooser).
On the web build every call is a safe no-op or falls back to a browser equivalent.

## Permissions
Media audio / storage read, microphone (recorder), notifications, foreground media service, wake lock, battery-optimisation exemption. WhatsApp, Facebook and Termux are declared as queries so they can be targeted.

## Data
- IndexedDB `prodigy_syncing_db`, version 6, stores: songs, notes, lyrics, playlists, links, meta, recs, videos, vfiles, images, ifiles. Removing an item in the app never touches the original file.
- localStorage: theme, preferences, collapsed left-panel sections, one-time reset flags.
- Export & Import (left panel) backs up the song list, playlists, folders, favourites, plays, notes, lyrics, links, Personal Notebook, snippets, AI chats, profile and settings. No audio, video or gallery files. Import merges.
- Clearing app data or uninstalling deletes the library, including video and gallery copies. Backups hold data only, never audio, video, gallery files or API keys.

## Troubleshooting
- **APK build fails at patch step**: `cap add android` failed, check the Generate step log.
- **Share does nothing / "needs Android 10"**: `shareImage` needs Android 10+. On older phones use Save and attach manually.
- **WhatsApp not listed**: install it; the chooser opens as fallback.
- **Facebook asks to log in again**: cookies persist in the browser settings; keep cookies switched on.
- **Browser covers the player**: tap ▾ to minimise it to the small bar, or close it with ✕.
- **Export says "native save failed"**: needs Android 10+; the browser fallback download is used instead.
- **Lyrics not found**: use Search, pick the match, or Edit and paste.
- **AI 403 / 404**: dead model on your key; the app migrates to the next live model, check the key in API Vault.
- **Old look after update (web)**: close and reopen the tab so the new service worker activates.
- **Artwork missing**: Metadata → Get artwork, or Settings → Auto-fetch artwork.
- **Something broke or a banner says a module failed**: Console → Diagnostics → Copy report and send it.
- **Auto-backup did nothing**: needs the APK on Android 10+. Each backup is a new dated file in Download/Prodigy (the app cannot delete old ones, so clear them by hand now and then).

## Known limits
- Spotify audio cannot be downloaded; Spotify embeds may only play previews on free accounts.
- Facebook login can be challenged by Facebook inside any WebView.
- `build-apk.yml` signs with your release key when the `RELEASE_KEYSTORE_*` secrets exist (run `bash scripts/setup-signing.sh` once in Termux), otherwise with the debug key from `DEBUG_KEYSTORE_B64`, and publishes the APK as a GitHub Release. Use `release-apk.yml` for the Play Store AAB (see Install without warnings).

## Install without warnings (Play Protect "unknown app")
No code in the app can switch off Android's install warnings; they come from Play Protect and the signing key. What actually removes them:
1. **Sign a release build**: add repo secrets `RELEASE_KEYSTORE_B64`, `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD`, run `release-apk.yml`. Never lose or change that keystore.
2. **Register as an Android developer** (Android Developer Console). Google is rolling out developer verification for certified devices: required from Sept 2026 in Brazil, Indonesia, Singapore and Thailand and worldwide from 2027.
3. **Publish on Google Play** (Internal testing needs no public review) using the AAB from the same workflow: installs with no warnings. Play also needs a current target SDK (Capacitor 7 or newer).
4. **ADB**: `adb install app-release.apk` from a computer skips the unknown-source prompt.
Until then, tap More details, Install anyway.
